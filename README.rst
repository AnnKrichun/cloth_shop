====================================
Clothing Shop Management System v19
====================================

This Odoo 19 module delivers an automated ecosystem for custom apparel retail operations.

Key Features
============
* Comprehensive grid logging across Brands, Sizes, and Collections.
* Dynamic multi-currency purchase order logs converting automated tag margins.
* Live PrivatBank commercial API rate synchronization on a daily session basis.
* Multi-level security matrix explicitly dividing Sales Managers, Product Managers, and Administrators.
* Advanced AVCO price calculation wizards updating live retail logs cascades.
